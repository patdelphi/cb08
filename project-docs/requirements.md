# CB08 录音笔 BLE Web 应用 — 需求规格

版本：1.0
创建时间：2026-08-20
最后更新：2026-09-09

## 1. 项目背景

CB08/QS668 录音笔通过 BLE（低功耗蓝牙）与上位机通信。本项目开发一个基于 Web Bluetooth API 的浏览器端应用，用于设备控制、文件管理、实时音频接收与转写。

## 2. 用户角色

- **开发者/测试人员**：使用本工具调试设备协议、验证固件功能
- **终端用户**：通过浏览器连接录音笔，管理录音文件

## 3. 功能需求

### 3.1 设备连接（P0）

| 编号 | 需求 | 优先级 |
|------|------|--------|
| CON-01 | 通过 Web Bluetooth 扫描广播 AE20 服务的设备 | P0 |
| CON-02 | 兼容扫描模式：acceptAllDevices，用户手动选择 | P0 |
| CON-03 | GATT 连接重试（5 次），应对设备连后即断 | P0 |
| CON-04 | 断线自动清理状态，UI 反馈 | P1 |
| CON-05 | 连接超时可配置（默认 60 秒） | P2 |

### 3.2 设备状态巡检（P0）

| 编号 | 需求 | 命令 |
|------|------|------|
| STA-01 | 读取电量百分比 | TYPE=0 CMD=3 |
| STA-02 | 读取剩余/总容量（KB） | TYPE=0 CMD=2 |
| STA-03 | 读取固件版本 | TYPE=0 CMD=10 |
| STA-04 | 同步时间（写入年月日时分秒） | TYPE=0 CMD=0 |
| STA-05 | 读取授权码 | TYPE=0 CMD=12 |
| STA-06 | 一键巡检（批量执行上述全部） | 组合 |

### 3.3 文件管理（P0）

| 编号 | 需求 | 命令 |
|------|------|------|
| FILE-01 | 读取文件列表（count/time/size，BE 解析） | TYPE=2 CMD=1 |
| FILE-02 | 下载文件（WAV 直下，Opus 需封装） | TYPE=2 CMD=4 |
| FILE-03 | 下载请求 2-2 始终整帧单写（preserveSeq=true） | — |
| FILE-04 | 删除单个文件（需启用"允许删除"开关） | TYPE=2 CMD=5 |
| FILE-05 | 删除全部文件（需二次确认） | TYPE=2 CMD=6 |
| FILE-06 | 分段导入文件到设备 | TYPE=2 CMD=3 |

### 3.4 录音控制（P1）

| 编号 | 需求 | 命令 |
|------|------|------|
| REC-01 | 开始录音 | TYPE=3 CMD=0 |
| REC-02 | 保存录音 | TYPE=3 CMD=1 |
| REC-03 | 暂停录音 | TYPE=3 CMD=2 |
| REC-04 | 继续录音 | TYPE=3 CMD=3 |
| REC-05 | 查询录音状态/时长/文件名 | TYPE=3 CMD=4 |
| REC-06 | 读取/设置增益 | TYPE=3 CMD=5/6 |

### 3.5 实时音频（P2）

| 编号 | 需求 |
|------|------|
| RT-01 | 接收 AE22 通知的 Opus 音频流 |
| RT-02 | Opus → Ogg 封装落盘（可播放 .ogg） |
| RT-03 | Opus → WAV 转换（WebCodecs 解码 → PCM → WAV） |
| RT-04 | 实时播放（WebCodecs → AudioContext） |
| RT-05 | 波形显示 |

### 3.6 ASR 语音转写（P2）

| 编号 | 需求 |
|------|------|
| ASR-01 | 分段提交 Opus 流到后端（800ms / 600-3200B 分段） |
| ASR-02 | 后端接口 `/api/qs668/transcribe` 接收并返回文本 |
| ASR-03 | 转写结果实时显示 |
| ASR-04 | 转写文本导出 |

### 3.7 调试工具（P1）

| 编号 | 需求 |
|------|------|
| DBG-01 | 原始命令构造器（手动指定 TYPE/CMD/PAYLOAD） |
| DBG-02 | 协议自检（CRC 向量、帧构造、半帧重组、BE 解析） |
| DBG-03 | 通信日志（TX/RX 带时间戳，可导出） |

### 3.8 界面（P1）

| 编号 | 需求 |
|------|------|
| UI-01 | 中/英文双语切换 |
| UI-02 | 白天/夜间主题切换 |
| UI-03 | 响应式布局（桌面优先） |
| UI-04 | 无构建工具，原生 HTML/CSS/JS |

## 4. 非功能需求

| 编号 | 需求 |
|------|------|
| NFR-01 | 浏览器兼容：Chrome 56+ / Edge 79+（Web Bluetooth） |
| NFR-02 | 无后端依赖（ASR 模块除外） |
| NFR-03 | 无 npm/构建工具，python -m http.server 即可运行 |
| NFR-04 | 所有 API 调用有异常处理和日志 |
| NFR-05 | 协议层可独立测试（Node.js） |

## 5. 约束

- BLE 通讯协议帧格式：`[0x5A][LEN][TYPE][CMD][SEQ][PAYLOAD...][CRC16-LE]`
- CRC：CRC-16/XMODEM，多项式 0x1021，初始值 0x0000
- 文件列表字段为大端（BE），其余为小端（LE）
- Opus 包固定 40 字节（Opus config 9，20ms/帧，16kHz 单声道）
